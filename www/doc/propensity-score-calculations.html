Understanding Propensity Score Sample Size Calculations

Power Analysis Tool Development Team

2025-10-26

Introduction

When planning observational studies that use propensity score weighting to adjust for confounding, sample size calculations become more complex than randomized controlled trials (RCTs). Two key challenges arise:

  1. Propensity score overlap: Poor overlap between treatment and control groups inflates variance
  2. Confounder-outcome association: Stronger confounding requires larger samples to achieve adequate power

This vignette explains two cutting-edge methods for propensity score sample size calculations:

  • Austin (2021): Variance Inflation Factor (VIF) approach based on propensity score overlap
  • Li et al. (2025): Extended approach accounting for both overlap AND confounder-outcome strength

Why Observational Studies Need Larger Samples

In an RCT, randomization ensures balance between treatment groups. In observational studies, propensity score weighting attempts to recreate this balance, but at a cost:

  • Increased variance: Weighting observations by inverse probability increases variance
  • Loss of effective sample size: Not all observations contribute equally
  • Confounding strength: Stronger confounding requires more data to adjust properly

Key insight from Li et al. (2025): Previous methods (including Austin 2021) only accounted for overlap, ignoring the strength of confounder-outcome association. This can lead to underpowered studies.

Method 1: Austin (2021) VIF Approach

Overview

Austin (2021) showed that sample size requirements for propensity score-weighted studies can be approximated by:

\[ N_{PS} = N_{RCT} \times VIF \]

where the Variance Inflation Factor (VIF) depends on:

  • C-statistic of the propensity score model (higher = better discrimination = more separation)
  • Treatment prevalence (balanced groups = lower VIF)
  • Weight type (ATE, ATT, ATO, ATM, ATEN)

Weight Types Explained

Propensity Score Weighting Methods
Weight Name Target Efficiency
ATE Average Treatment Effect Full population Lowest (highest VIF)
ATT Average Treatment on Treated Treated population only Moderate
ATO Average Treatment on Overlap Overlap population (best balance) Highest (lowest VIF)
ATM Matching Weights Matched subset High
ATEN Entropy Weights Entropy-weighted subset High

Example: Austin VIF Calculation

Suppose we’re planning an observational study comparing a new drug to standard care. From a pilot study or literature:

  • RCT would require N = 400 for 80% power
  • Treatment prevalence: 30%
  • Propensity score model C-statistic: 0.75
  • Using ATE weights (target full population effect)
library(PowerAnalysisTool)

# Calculate VIF using Austin (2021) method
vif_austin <- estimate_vif_propensity_score(
  c_statistic = 0.75,
  prevalence_pct = 30,
  weight_type = "ATE"
)

# Required sample size for observational study
n_observational <- 400 * vif_austin

cat("VIF:", vif_austin, "\n")
cat("Required N:", ceiling(n_observational), "\n")
cat("Increase vs RCT:", paste0("+", round((vif_austin - 1) * 100, 1), "%\n"))

Typical output: VIF ≈ 1.8, requiring N ≈ 720 (+80% vs RCT)

Interpreting VIF Values

VIF Interpretation Guide
VIF_Range Interpretation Recommendation
< 1.3 Low efficiency loss PS weighting highly efficient
1.3 - 2.0 Moderate efficiency loss PS weighting acceptable; consider ATO for better efficiency
2.0 - 3.0 Substantial efficiency loss Use overlap weights (ATO) or matching weights (ATM)
> 3.0 Severe efficiency loss PS weighting may not be feasible; consider alternatives

Limitations of Austin’s Approach

Austin’s VIF method has a key limitation: it does not account for confounder-outcome strength.

Consider two scenarios with identical propensity score overlap (C-statistic = 0.75):

  1. Weak confounding: Confounder explains 5% of outcome variance (R² = 0.05)
  2. Strong confounding: Confounder explains 35% of outcome variance (R² = 0.35)

Austin’s VIF would be identical for both scenarios, but the strong confounding scenario requires a much larger sample to achieve adequate power after adjustment.

This is where Li et al. (2025) extends the methodology.

Method 2: Li et al. (2025) Extended Approach

Overview

Li et al. (2025) published a groundbreaking method that accounts for both overlap and confounding strength:

\[ N_{PS} = \frac{V_{adjusted} (z_{1-\alpha/2} + z_{\beta})^2}{\tau^2} \]

where \(V_{adjusted}\) incorporates:

  1. Baseline variance (like RCT)
  2. Overlap penalty (like Austin)
  3. Confounding penalty (NEW: based on confounder-outcome R²)

Key Innovation: Confounder-Outcome R²

The confounding penalty is:

\[ \text{Confounding Penalty} = \frac{1}{1 - \rho^2} \]

where \(\rho^2\) is the R-squared representing how much outcome variance is explained by confounders.

Example values:

Confounding Strength and Sample Size Impact
R_Squared Confounding Penalty Impact
0.01 Weak 1.01× Minimal inflation
0.10 Moderate 1.11× ~11% sample increase
0.20 Strong 1.25× ~25% sample increase
0.35 Very Strong 1.54× ~54% sample increase

Overlap Coefficient (Bhattacharyya φ)

Li et al. use the Bhattacharyya coefficient (φ) to quantify propensity score overlap:

  • φ = 1.0: Perfect overlap (distributions identical)
  • φ = 0.9: Excellent overlap
  • φ = 0.75: Good overlap
  • φ = 0.5: Fair overlap
  • φ < 0.5: Poor overlap

Relationship to C-statistic: Higher C-statistic → lower overlap coefficient

Example: Li et al. (2025) Calculation

Using the same scenario, but now incorporating confounding strength:

# From pilot study: confounder-outcome R² = 0.20 (moderate confounding)
# Overlap coefficient φ = 0.75 (corresponds to C-stat ≈ 0.75)

li_result <- calculate_n_li_2025(
  effect_size = 0.2,           # Standardized effect (Cohen's d)
  alpha = 0.05,
  power = 0.80,
  treatment_prop = 0.30,       # 30% treated
  overlap_phi = 0.75,          # Good overlap
  rho_squared = 0.20,          # Moderate confounding
  weight_type = "ATE",
  outcome_var = 1
)

cat("Required N:", li_result$n_required, "\n")
cat("Effective N:", li_result$n_effective, "\n")
cat("VIF (Li 2025):", round(li_result$vif, 2), "\n")
cat("Overlap penalty:", round(li_result$overlap_penalty, 2), "\n")
cat("Confounding penalty:", round(li_result$confounding_penalty, 2), "\n")

Typical output: - Required N ≈ 950 - VIF ≈ 2.4 (vs 1.8 using Austin) - Overlap penalty: 1.06× - Confounding penalty: 1.25×

Practical Workflow

Step 1: Determine RCT Sample Size

First, calculate the sample size you would need for an equivalent RCT using standard methods:

# For two-proportion comparison
library(pwr)

rct_result <- pwr.2p.test(
  h = 0.2,           # Effect size (Cohen's h or standardized difference)
  sig.level = 0.05,
  power = 0.80,
  alternative = "two.sided"
)

n_rct <- ceiling(rct_result$n * 2)  # Total sample size

Step 2: Estimate Propensity Score Model Performance

From pilot data or literature, estimate:

  1. C-statistic (or AUC) of propensity score model
  2. Treatment prevalence in your population
  3. Overlap coefficient (or estimate from C-statistic)

If you only have C-statistic, approximate overlap: - C = 0.70 → φ ≈ 0.85 - C = 0.75 → φ ≈ 0.75 - C = 0.80 → φ ≈ 0.65 - C = 0.85 → φ ≈ 0.50

Step 3: Estimate Confounder-Outcome Association

Determine R² from:

  • Pilot study regression: Outcome ~ Confounder(s), extract R²
  • Literature: Find similar studies reporting confounder effects
  • Expert judgment: Conservative estimate (e.g., R² = 0.20 if moderate)

Important: Use the R² from a model WITHOUT the treatment variable, only confounders → outcome.

Step 4: Choose Weighting Method

Select based on your target estimand:

  • ATE: Full population effect (most generalizable, highest VIF)
  • ATT: Effect in treated population (useful for treatment decisions)
  • ATO: Effect in overlap population (most efficient, lowest VIF, but less generalizable)

Step 5: Calculate Required Sample Size

Using Austin (2021) only:

vif <- estimate_vif_propensity_score(
  c_statistic = 0.75,
  prevalence_pct = 30,
  weight_type = "ATE"
)

n_required_austin <- ceiling(n_rct * vif)

Using Li et al. (2025) (RECOMMENDED):

li_result <- calculate_n_li_2025(
  effect_size = 0.2,
  alpha = 0.05,
  power = 0.80,
  treatment_prop = 0.30,
  overlap_phi = 0.75,
  rho_squared = 0.20,
  weight_type = "ATE",
  outcome_var = 1
)

n_required_li <- li_result$n_required

Step 6: Sensitivity Analysis

Test robustness to assumptions:

sensitivity <- generate_ps_sensitivity_analysis(
  n_rct = 400,
  treatment_prev_pct = 30,
  c_stat = 0.75,
  overlap_phi = 0.75,
  rho_squared = 0.20,
  weight_type = "ATE",
  method = "Both"
)

print(sensitivity)

This generates a table showing sample size requirements under various overlap and confounding scenarios, helping you understand worst-case and best-case scenarios.

Case Study: Real-World Example

Scenario

A health system wants to compare outcomes for patients receiving a new diabetes medication vs standard therapy. From EHR data:

  • Treatment prevalence: 35% receive new medication
  • PS model C-statistic: 0.78 (good discrimination)
  • Overlap: φ ≈ 0.70 (estimated from C-stat)
  • Confounding: Baseline HbA1c explains R² = 0.25 of outcome variance
  • Target: ATE (full population effect)
  • Design: 80% power, α = 0.05, effect size d = 0.25

Calculations

RCT Sample Size (Baseline)

# Continuous outcome, two groups
pwr_result <- pwr.t.test(
  d = 0.25,
  sig.level = 0.05,
  power = 0.80,
  type = "two.sample",
  alternative = "two.sided"
)

n_rct <- ceiling(pwr_result$n * 2)
# Result: N = 506

Austin (2021) Estimate

vif_austin <- estimate_vif_propensity_score(
  c_statistic = 0.78,
  prevalence_pct = 35,
  weight_type = "ATE"
)
# VIF ≈ 2.1

n_austin <- ceiling(506 * vif_austin)
# Result: N ≈ 1,063 (+110% vs RCT)

Li et al. (2025) Estimate (Recommended)

li_result <- calculate_n_li_2025(
  effect_size = 0.25,
  alpha = 0.05,
  power = 0.80,
  treatment_prop = 0.35,
  overlap_phi = 0.70,
  rho_squared = 0.25,
  weight_type = "ATE",
  outcome_var = 1
)
# Required N ≈ 1,380
# VIF ≈ 2.7 (vs 2.1 for Austin)

n_li <- li_result$n_required
# Result: N ≈ 1,380 (+173% vs RCT)

Interpretation

  • RCT baseline: 506 patients
  • Austin (ignoring confounding strength): 1,063 patients (+110%)
  • Li et al. (accounting for confounding): 1,380 patients (+173%)

Conclusion: Using Austin’s method alone would underpower the study by ~23%. The team should plan for 1,380 patients to achieve adequate power given moderate confounding (R² = 0.25).

Exploring Alternatives

The team also considers overlap weights (ATO) for better efficiency:

li_result_ato <- calculate_n_li_2025(
  effect_size = 0.25,
  alpha = 0.05,
  power = 0.80,
  treatment_prop = 0.35,
  overlap_phi = 0.70,
  rho_squared = 0.25,
  weight_type = "ATO",  # Changed to overlap weights
  outcome_var = 1
)

# Required N ≈ 965 (vs 1,380 for ATE)
# VIF ≈ 1.9 (vs 2.7 for ATE)

Trade-off: ATO reduces sample size to 965 (-30% vs ATE), but changes estimand from full population to overlap population only.

Recommendations

Which Method to Use?

  1. Always start with Li et al. (2025) if you have an estimate of confounder-outcome strength
    • More accurate accounting for both overlap and confounding
    • Prevents underpowered studies
  2. Use Austin (2021) as a minimum if R² is unknown
    • Conservative assumption: R² = 0 (no confounding penalty)
    • Provides lower bound on sample size
  3. Conduct sensitivity analysis to explore scenarios
    • Test worst-case: poor overlap (φ = 0.5), strong confounding (R² = 0.30)
    • Test best-case: good overlap (φ = 0.85), weak confounding (R² = 0.05)

Obtaining R² Estimates

If you don’t have pilot data, consider:

  1. Literature review: Find similar studies and extract reported R² or effect sizes
  2. Expert consultation: Ask domain experts for plausible confounder effect magnitudes
  3. Conservative assumption: Use R² = 0.20 (moderate) as default
  4. Pilot study: Collect small sample to estimate PS model and confounder-outcome association

When to Use Overlap Weights

Consider ATO (overlap weights) if:

  • VIF > 2.5 with ATE weights
  • Overlap coefficient φ < 0.6
  • Your research question allows restricting to overlap population

Caution: ATO changes the estimand. Clearly report that results apply to the overlap population, not the full population.

Summary

Propensity score sample size calculations require accounting for efficiency loss due to:

  1. Propensity score overlap (Austin 2021)
  2. Confounder-outcome association (Li et al. 2025)

Key takeaways:

  • Observational studies require larger samples than RCTs (typically 1.5× to 3× depending on overlap and confounding)
  • Li et al. (2025) method is more accurate than Austin (2021) when confounding is present
  • Ignoring confounding strength can underpower studies by 20-50%
  • Overlap weights (ATO) offer better efficiency but change the target estimand
  • Sensitivity analysis is essential to understand robustness to assumptions
