## Key Files Explained

### Package Metadata

| File | Purpose | Editable? | Generated? |
|------|---------|-----------|------------|
| **DESCRIPTION** | Package metadata, dependencies | ✅ Yes | ❌ Manual |
| **NAMESPACE** | Exported functions | ❌ No | ✅ roxygen2 |
| **LICENSE** | License text | ✅ Yes | ❌ Manual |
| **README.md** | User-facing documentation | ✅ Yes | ❌ Manual |
| **NEWS.md** | Version changelog | ✅ Yes | ❌ Manual |

### Core Application Files

| File | Purpose | Lines | Editable? |
|------|---------|-------|-----------|
| **R/run_app.R** | Launches the Shiny app | ~30 | ✅ Rarely |
| **R/app_ui.R** | Main UI scaffolding | ~100 | ✅ Yes |
| **R/app_server.R** | Main server logic | ~150 | ✅ Yes |
| **R/app_config.R** | Configuration helpers | ~50 | ✅ Rarely |
| **app.R** | Deployment wrapper | 5 | ❌ Auto-gen |

### Module Files (R/mod_*.R)

| Pattern | Example | Purpose |
|---------|---------|---------|
| `mod_##_name.R` | `mod_01_single_proportion.R` | Analysis module |
| `mod_common.R` | `mod_missing_data.R` | Cross-cutting module |

**Each module contains:**
- `mod_XX_name_ui(id)` - UI function
- `mod_XX_name_server(id)` - Server function

### Business Logic (R/fct_*.R)

| File | Purpose | Example Functions |
|------|---------|-------------------|
| `fct_effect_size.R` | Effect size calculations | `calc_effect_measures()`, `cohens_d_to_r()` |
| `fct_power_calculations.R` | Power calculations | `calculate_two_group_power()` |
| `fct_sample_size.R` | Sample size calculations | `calculate_sample_size()` |
| `fct_propensity_score.R` | PS calculations | `calculate_ps_vif()` |

### Utilities (R/utils_*.R)

| File | Purpose | Example Functions |
|------|---------|-------------------|
| `utils_plot.R` | Plot helpers | `create_power_curve_plot()`, `generate_n_sequence()` |
| `utils_text.R` | Text formatting | `format_numeric()`, `create_result_text()` |
| `utils_ui.R` | UI components | `create_numeric_input_with_tooltip()` |
| `utils_ui_help.R` | Help content | `create_contextual_help_*()` |

## File Naming Conventions

### Modules: `mod_##_description.R`

**Format:** `mod_[number]_[description].R`

**Examples:**
- `mod_01_single_proportion.R`
- `mod_02_power_two_group.R`
- `mod_11_propensity_score.R`

**Numbering:**
- Sequential by order in UI
- Use leading zeros (01, 02, not 1, 2)
- Leave gaps for future insertions (01, 05, 10)

### Business Logic: `fct_description.R`

**Format:** `fct_[description].R`

**Examples:**
- `fct_effect_size.R`
- `fct_power_calculations.R`
- `fct_survival_analysis.R`

**Purpose:** Pure R functions (no reactivity)

### Utilities: `utils_category.R`

**Format:** `utils_[category].R`

**Examples:**
- `utils_plot.R`
- `utils_text.R`
- `utils_ui_inputs.R`

**Purpose:** Helper functions (may include UI helpers)

### Tests: `test-filename.R`

**Format:** `test-[original_filename].R`

**Examples:**
- `test-fct_effect_size.R` (tests `fct_effect_size.R`)
- `test-mod_01_single_proportion.R` (tests module)

**Location:** `tests/testthat/`

## Where Does My Code Go?

Use this decision tree:

```
Is it a complete analysis tab?
├─ YES → R/mod_##_name.R
└─ NO
   ├─ Is it a statistical calculation?
   │  └─ YES → R/fct_*.R
   └─ Is it a UI helper?
      ├─ YES → R/utils_ui*.R
      └─ Is it a plotting function?
         ├─ YES → R/utils_plot.R
         └─ Is it text formatting?
            ├─ YES → R/utils_text.R
            └─ Other helper → R/utils_*.R
```

### Examples

**Q:** Where do I put a new power curve function?
**A:** `R/utils_plot.R` (plotting helper)

**Q:** Where do I put logistic regression power calculation?
**A:** `R/fct_logistic_power.R` (business logic)

**Q:** Where do I put a new "Power (Logistic)" tab?
**A:** `R/mod_12_power_logistic.R` (module)

**Q:** Where do I put a function to format odds ratios?
**A:** `R/utils_text.R` (text formatting helper)

**Q:** Where do I put CSS files?
**A:** `inst/app/www/css/` (static assets)

**Q:** Where do I put test data?
**A:** `tests/testthat/fixtures/` or `inst/extdata/`

## roxygen2 Tags Reference

### Common Tags

| Tag | Purpose | Example |
|-----|---------|---------|
| `@param` | Parameter description | `@param n Sample size` |
| `@return` | Return value description | `@return Numeric power (0-1)` |
| `@examples` | Usage examples | `@examples calculate_power(100, 0.5)` |
| `@export` | Export for users | `@export` |
| `@noRd` | Internal function (no help) | `@noRd` |
| `@importFrom` | Import specific function | `@importFrom shiny NS` |
| `@import` | Import entire package | `@import ggplot2` |

### When to Use @export vs @noRd

**Use `@export`:**
- `run_app()` - Main user-facing function
- Publicly documented functions
- Functions users call directly

**Use `@noRd`:**
- All module functions (`mod_*_ui`, `mod_*_server`)
- All business logic (`fct_*`)
- All helpers (`utils_*`)
- Internal functions

**Example:**
```r
#' Launch Power Analysis Tool
#'
#' @export
run_app <- function() { ... }

#' Calculate Two-Group Power
#'
#' @noRd
calculate_two_group_power <- function() { ... }
```

## DESCRIPTION File Format

```
Package: powerAnalysisTool
Title: Power and Sample Size Calculator for RWE Studies
Version: 1.0.0
Authors@R: person("Your", "Name", email = "you@example.com", role = c("aut", "cre"))
Description: Comprehensive Shiny application for power and sample size
    calculations in observational studies and real-world evidence research.
License: MIT + file LICENSE
Imports:
    shiny (>= 1.7.0),
    bslib (>= 0.5.0),
    pwr (>= 1.3.0),
    plotly (>= 4.10.0)
Suggests:
    testthat (>= 3.0.0),
    shinytest2
Encoding: UTF-8
LazyData: true
RoxygenNote: 7.2.3
```

### Sections

- **Imports:** Required packages (install with package)
- **Suggests:** Optional packages (for testing, vignettes)
- **Depends:** Rarely used (older R versions only)

### Add Dependencies

```r
# Add to Imports
usethis::use_package("dplyr")

# Add to Suggests
usethis::use_package("covr", type = "Suggests")
```

## .Rbuildignore Patterns

Files/dirs excluded from package build:

```
^.*\.Rproj$          # RStudio project file
^\.Rproj\.user$      # RStudio user files
^app\.R$             # Deployment wrapper (not in package)
^rsconnect$          # shinyapps.io deployment
^deploy$             # Docker deployment folder
^\.github$           # GitHub Actions
^docs/002-how-to-guides$    # How-to guides
^docs/004-explanation$      # Explanations
^PROPENSITY_SCORE_.*\.md$   # Temp docs
```

## Common Tasks Reference

### Create New Module

```r
golem::add_module(name = "12_power_logistic")
# Creates: R/mod_12_power_logistic.R
```

### Create New Function File

```r
golem::add_fct("logistic_power")
# Creates: R/fct_logistic_power.R
```

### Create New Utility File

```r
golem::add_utils("validation")
# Creates: R/utils_validation.R
```

### Add Dependency

```r
usethis::use_package("dplyr")
# Updates: DESCRIPTION
```

### Generate Documentation

```r
devtools::document()
# Updates: NAMESPACE, man/*.Rd
```

### Run Tests

```r
devtools::test()
# Runs: tests/testthat/test-*.R
```

### Check Package

```r
devtools::check()
# Runs: R CMD check
```

### Build Package

```r
devtools::build()
# Creates: ../powerAnalysisTool_1.0.0.tar.gz
```

### Install Package Locally

```r
devtools::install()
# Installs package from source
```

## File Size Guidelines

| File Type | Target Size | Max Size | Notes |
|-----------|-------------|----------|-------|
| **Module** | 150-200 lines | 300 lines | Split if larger |
| **Function file** | 100-200 lines | 400 lines | One concept per file |
| **Utility file** | 50-150 lines | 300 lines | Group related helpers |
| **app_ui.R** | 50-100 lines | 150 lines | Just module calls |
| **app_server.R** | 100-200 lines | 300 lines | Module calls + shared state |
